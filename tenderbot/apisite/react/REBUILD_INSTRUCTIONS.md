# Инструкция по пересборке React для dev режима

## Проблема

После изменений в конфигурации нужно пересобрать React приложение, чтобы оно работало правильно в dev режиме без префикса `/catalog/`.

## Решение

### Вариант 1: Пересборка для dev режима (рекомендуется)

```bash
cd tenderbot/apisite/react

# Убедитесь, что VITE_BASE_PATH не задан в .env (или удалите эту переменную)
# Файл .env должен быть пустым или не содержать VITE_BASE_PATH

# Удалите старую сборку (если есть)
rm -rf dist
# или в Windows:
# rmdir /s /q dist

# Пересоберите React БЕЗ base пути
npm run build
```

После пересборки:
- Статические файлы будут доступны по пути `/assets/...` вместо `/catalog/assets/...`
- FastAPI автоматически обработает запросы правильно
- Header должен отображаться на странице checkout

### Вариант 2: Использование Vite dev server (для разработки с hot reload)

Если вы хотите использовать hot reload во время разработки:

```bash
# Терминал 1: Запустите FastAPI
cd tenderbot/apisite
python main.py

# Терминал 2: Запустите Vite dev server
cd tenderbot/apisite/react
npm run dev
```

Затем откройте `http://localhost:3000` вместо `http://localhost:8001` для разработки фронтенда.

## Проверка

После пересборки проверьте:

1. Откройте `http://localhost:8001/checkout`
2. Откройте консоль браузера (F12) - не должно быть ошибок 404 для статических файлов
3. Header должен отображаться вверху страницы
4. Навигация должна работать

## Примечания

- FastAPI теперь автоматически обрабатывает запросы с префиксом `/catalog/` и без него
- Это позволяет работать как с dev сборкой (без префикса), так и с production сборкой (с префиксом через Nginx)
- Для production сборки установите `VITE_BASE_PATH=/catalog` в `.env` перед сборкой
