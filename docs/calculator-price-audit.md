## Готовые строки для замены в calculatorConfig.ts (только ❌ Обновить, та же модель в каталоге)

Перед применением проверить: лифтовые камеры в конфиге заложены дороже (антивандальность); подстановка каталога уравнивает их с обычными купольными — при необходимости оставить надбавку вручную.

```ts
// Лифтовая камера 2MP: было 18 500, каталог 15 400
priceKzt: 18_500 → 15_400  // IPC-3612-APF28-DL

// Лифтовая камера 4MP: было 26 000, каталог 19 900
priceKzt: 26_000 → 19_900  // IPC-3614-APF28-NB

// NVR308-64E: было 850 000, каталог 530 100
priceKzt: 850_000 → 530_100  // NVR308-64X

// NVR304-32E: было 420 000, каталог 124 800
priceKzt: 420_000 → 124_800  // NVR304-32B-IQ

// NVR302-16E: было 195 000, каталог 97 500
priceKzt: 195_000 → 97_500  // NVR302-16B-IQ

// Коммутатор управляемый 24п (аплинк): было 45 000, каталог 8 990 — уточнить модель (NS-1010-8GT = 8п неуправл.)
priceKzt: 45_000 → 8_990  // NS-1010-8GT

// Вызывная панель IP: было 85 000, каталог 56 600
priceKzt: 85_000 → 56_600  // C313S

// Контроллер доступа: было 35 000, каталог 5 265 — уточнить: в каталоге может быть доп. блок GVAE11
priceKzt: 35_000 → 5_265  // GVAE11

// Вызывная панель (вход): было 250 000, каталог 101 250
priceKzt: 250_000 → 101_250  // OEU-201S-HMK-W
```

Повторный запуск аудита: `node scripts/audit-calculator-prices.mjs`.
