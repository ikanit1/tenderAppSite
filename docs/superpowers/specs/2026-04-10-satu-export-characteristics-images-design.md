# Satu XLSX Export: характеристики, фото, SEO

**Дата:** 2026-04-10
**Статус:** Утверждён

## Цель

Довести экспорт `export_satu_excel.py` до полного соответствия формату импорта Satu.kz:
- Добавить характеристики товаров (блоки Название/Измерение/Значение)
- Обеспечить фото для всех товаров (скачивание с complex.com.kz при отсутствии)
- Добавить SEO-поля (HTML_заголовок, HTML_описание)
- Добавить поле Страна_производитель

## 1. Характеристики товаров

### Источник данных
- `portal_export/{model}/product.json` → поле `attributes` (dict)
- Пример: `{"Производитель": "Schneider Electric", "Серия": "ACTI9", "Номин. ток": "4 А"}`

### Фильтрация
Исключаемые ключи (blacklist):
- `"Итого"` — содержит цену, не характеристика
- `"Код Elevel"` — внутренний код поставщика

### Парсинг единиц измерения
Whitelist единиц для regex-извлечения из значения:
```
мм²|мм|см|м|км|мкм|г|кг|т|шт|В|А|Вт|кВт|МВт|Гц|кГц|МГц|°C|°|Ом|кОм|МОм|Ф|мкФ|нФ|пФ|Гн|лм|лк|Па|кПа|МПа|бар|дБ|л|мл
```

Логика:
1. Значение `"44.5 мм"` → Измерение=`"мм"`, Значение=`"44.5"`
2. Значение `"Да"` → Измерение=`""`, Значение=`"Да"` (единица не найдена)
3. Значение `"-20…+55"` → Измерение=`""`, Значение=`"-20…+55"`
4. Значение `"4 А"` → Измерение=`"А"`, Значение=`"4"`
5. Значение `"1.0...25.0 мм²"` → Измерение=`"мм²"`, Значение=`"1.0...25.0"`

### Структура в XLSX
- Блоки из 3 столбцов в конце таблицы (после всех основных столбцов)
- Количество блоков = max(len(attributes)) среди всех товаров
- Товары с меньшим количеством характеристик — оставшиеся столбцы пустые
- Порядок характеристик для каждого товара: как в оригинальном dict

## 2. Загрузка фото с complex.com.kz

### Когда скачивать
Если в `portal_export/{model}/` нет файлов `image_*.jpg/png/webp` И в `product.json` есть `product_url`.

### Алгоритм (`ensure_product_images()`)
1. Проверить наличие image-файлов в папке — если есть, пропуск
2. Прочитать `product_url` из `product.json`
3. HTTP GET на product_url с User-Agent браузера
4. Парсить HTML: найти изображения товара (основное фото + галерея)
5. Скачать каждое изображение, сохранить как `image_01.jpg`, `image_02.jpg` и т.д.
6. Обновить `product.json` → `images` и `images_count`

### HTTP-заголовки
```python
HEADERS = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,image/webp,*/*;q=0.8",
}
```

### Ограничения
- Таймаут на запрос: 15 секунд
- Пауза между запросами: 0.5-1 сек (не DDoS-ить complex.com.kz)
- При ошибке HTTP/парсинга — пропускаем товар, логируем в stderr
- Максимум 10 фото на товар

### Размещение
Новая функция в `export_satu_excel.py` (не в utils.py — она специфична для Satu-экспорта).

## 3. SEO-поля

### HTML_заголовок (до 250 символов)
Шаблон: `{Название_позиции} — Купить в Астане по выгодной цене | G&R Group`

Если длина > 250 символов — обрезаем название, суффикс сохраняем.

### HTML_описание (до 250 символов)
Шаблон: `{первые ~150 символов описания без HTML-тегов}. Купить в Астане с доставкой. G&R Group`

Логика:
1. Удалить все HTML-теги из description
2. Взять первые 150 символов, обрезать по последнему пробелу
3. Добавить `. Купить в Астане с доставкой. G&R Group`
4. Итого до 250 символов

## 4. Страна_производитель

Извлечение из `attributes`:
- Ключи для поиска: `"Страна"`, `"Страна производства"`, `"Страна-производитель"`, `"Страна производитель"`, `"Country"`
- Первое найденное совпадение → значение столбца
- Если не найдено → пустая строка

## 6. Pipeline данных

### Изменения в `_build_portal_by_model()`
Добавить `attributes` в record:
```python
record = {
    "description": description,
    "image_paths": image_paths,
    "folder": folder.name,
    "attributes": attrs,  # NEW
}
```

### Изменения в `load_products_for_satu()`
Пробросить `attributes` в выходной dict:
```python
out.append({
    ...
    "attributes": portal.get("attributes", {}),  # NEW
})
```

### Изменения в `build_full_excel()`
1. Первый проход: определить max_attrs = max(len(p["attributes"]) для всех p)
2. Добавить заголовки: 22 основных + max_attrs × 3 блоков характеристик
3. Для каждого товара: заполнить блоки характеристик с парсингом единиц

## 8. Не делаем (осознанно)

- GTIN, MPN, способ упаковки — нерелевантно для B2B-сегмента
- Скидки и ярлыки — управляются через кабинет Satu
- Подарки, сопутствующие — нет данных
- ID_группы_разновидностей — нет вариантов товаров в текущей модели
